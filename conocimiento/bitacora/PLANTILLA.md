# Bitácora de sesiones — gamma / order flow

Objetivo: 15 sesiones antes de evaluar cualquier gasto en suscripciones.
Una línea por día. Sin adornos, sin justificaciones.

| # | Fecha | Flip (ES) | Abrió arriba/abajo | Día fue rango/tendencia | ¿El nivel aguantó? | Nota corta |
|---|-------|-----------|--------------------|-------------------------|--------------------|------------|
| 1 |       |           |                    |                         |                    |            |

## Cómo llenarla
- **Flip (ES):** el gamma flip convertido a precio de futuro, el que dibujaste.
- **Abrió arriba/abajo:** de qué lado del flip abrió Chicago.
- **Rango/tendencia:** cómo terminó siendo el día, no cómo lo esperabas.
- **¿Aguantó?:** sí / no / no se testeó.
- **Nota:** solo si pasó algo que la tabla no captura.

## La pregunta que contesta esta bitácora
¿El régimen de gamma predijo el tipo de día? Si después de 15 sesiones no hay
relación visible, el problema no es la velocidad de los datos y no hay que pagar nada.
